# Run 
## chạy lần đầu
```
Set-Location C:\xampp\htdocs\DTDM
npm install
```
## Terminal 1 — backend:
```
Set-Location C:\xampp\htdocs\DTDM
npm run server
```
## Terminal 2 — frontend:
```
Set-Location C:\xampp\htdocs\DTDM
npm run dev
```
## Chạy bản build thay cho chế độ dev (tùy chọn):
```
Set-Location C:\xampp\htdocs\DTDM
npm run build
npm start
```
